1. AKUN SUPER ADMIN (HAK AKSES PENUH SELURUH SISTEM)
--------------------------------------------------------------------------------
Deskripsi: Memiliki kendali mutlak untuk mengelola seluruh data website,
           pengaturan halaman beranda/tentang/kontak, manajemen pengguna admin,
           naskah, buku, layanan, dan transaksi pesanan.

* Akun Utama:
  - Email    : admin@persispers.com
  - Password : persispers
  - Role     : Super Admin (Akses Penuh)

* Akun Alternatif:
  - Email    : superadmin@penerbitpersis.com
  - Password : persispers
  - Role     : Super Admin (Akses Penuh)


--------------------------------------------------------------------------------
2. AKUN ADMIN REDAKSI & PENERBITAN NASKAH
--------------------------------------------------------------------------------
Deskripsi: Mengelola pengajuan naskah masuk dari penulis, konversi KTI,
           layanan penerbitan, dan katalog buku ber-ISBN.
           (Menu Pengaturan Web & Manajemen Pengguna otomatis TERSEMBUNYI).

* Akun Redaksi:
  - Email    : redaksi@penerbitpersis.com
  - Password : persispers
  - Role     : Admin Redaksi (Naskah & Layanan Web)


--------------------------------------------------------------------------------
3. AKUN OPERATOR TRANSAKSI, PENGIRIMAN & KASIR (KHUSUS PEMESANAN)
--------------------------------------------------------------------------------
Deskripsi: Khusus menangani transaksi pesanan buku masuk, update status order
           (Pending, Dipacking, Dikirim, Selesai), input nomor resi ekspedisi,
           cetak label pengiriman/invoice, dan live chat dengan pembeli.
           (Menu Naskah, Layanan, Buku, & Pengaturan Web otomatis DIBLOKIR/TERSEMBUNYI).

* Operator Transaksi & Kasir:
  - Email    : operator@persispers.com
  - Password : persispers
  - Role     : Operator Transaksi & Pengiriman

* Operator Pengiriman & Logistik Gudang:
  - Email    : pengiriman@penerbitpersis.com
  - Password : persispers
  - Role     : Operator Transaksi & Pengiriman

* Operator Keuangan & Faktur:
  - Email    : keuangan@penerbitpersis.com
  - Password : persispers
  - Role     : Operator Transaksi & Pengiriman

                           CATATAN KEAMANAN
================================================================================

   php artisan db:seed --class=AdminSeeder --force

2. Kata sandi default dapat diubah sewaktu-waktu melalui menu:
   Profil Saya -> Ganti Kata Sandi (di pojok kanan atas panel admin).
